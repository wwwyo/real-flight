# 敵編隊

[English](prd.md)

[出撃 MVP](../sortie-mvp/prd.ja.md) の続き。

## Problem

出撃 MVP では、操縦者は印刷した標的を撃墜する。標的は動かず、撃ち返してもこない。照準は合わせられるが、機体を脅かすものがないので、出撃が戦いではなく射撃練習に感じられる。標的は明るい場所で約 1.3 m 以内でしか認識されず、飛び回る余地も小さい。

## 導出

Story は、操縦者が実物の機体で現実の空の戦いに飛び込むこと。MVP で、操縦者が飛ばして撃てることは示せた。ここでは戦いのもう一方を足す。数で押し寄せ、機体を攻撃し、機体を飛ばしてかわさなければならない敵である。参考にするのは縦スクロールシューティングというジャンルで、自機に向かって敵機の編隊が次々に来て、弾を撃ち、撃ち落とすと得点になる。

## Overview

操縦者は離陸し、部屋の中でホバリングする。仮想の敵機が編隊を組んで機体のまわりに飛来し、機体を撃ってくる。機体の向きや高さを変えても敵機は空中の同じ場所にとどまるので、操縦者は実機を飛ばして狙い、射線から機体を動かしてかわす。危ないときは機体に本物の宙返りをさせ、その間はどの弾も当たらない。出撃の最後の敵は印刷した標的で、撃墜すれば勝ち、先に装甲が尽きれば負け。コックピットは結果を表示するだけで、機体は操縦者が着陸させるまで操縦者の手にある。コックピットと録画の音が戦いを伝える。

### Goals

- 攻撃してくる敵によって、出撃が MVP より戦いらしく感じられるかを確かめる。
- 実機を飛ばして狙い、かわすことが楽しさの中心になるか、つまり実物の機体であることがゲームにとって意味を持つかを確かめる。
- 射撃練習ではなく戦いが映った出撃映像を、TCIC の応募（締切は 11/4 に延長）のために得る。

### Non-Goals

- スクロールの代わりに、実際のコースを前進して飛ぶこと。部屋が狭く、屋内向けに速度を 40% に抑えているため。飛ばせる場所ができたら戻ってくる。
- 複数の機体や操縦者、対戦
- 動く物理的な敵
- 屋外飛行
- 特定の既存ゲームの再現。参考にするのはジャンルで、機体・ステージ・名前・HUD は独自に作る。

## Glossary

- **Wave（編隊）**: いっしょに飛来し、攻撃し、撃墜されるか去っていく敵機の一群。
- **Enemy aircraft（敵機）**: 編隊の中の仮想の機体。コックピットの映像と出撃映像の中にだけ存在する。[Target（標的）](../../../AGENTS.md#glossary) と違い、部屋には何も置かない。
- **Armor（装甲）**: 出撃に負けるまでに、機体が敵の弾を何発受けられるか。
- **Evasive flip（宙返り回避）**: 操縦者が出させる機体の本物の宙返り。その間、敵の弾は機体に当たらない。

Wave と Enemy aircraft は、出撃と出撃映像でも使うので、ready になったら [AGENTS.md の Glossary](../../../AGENTS.md#glossary) に移す。

## Domain Model

- 出撃は、編隊が順に来たあと、部屋に置いた標的が続く。最後の標的を撃墜すれば勝ち、装甲が尽きれば負け。どちらでもコックピットは結果を表示し、操縦者は着陸させるまで飛び続ける。
- 敵機も標的も、同じトリガーと照準で撃つ。敵機は飛び回って撃ってくる。標的は動かず、撃ってこない。
- 敵の弾は、撃った瞬間に機体がいた方向へ飛ぶ。機体に届いたとき、機体がよけていなければ当たる。
- 編隊を全機撃墜するとパワーアップが手に入り、しばらく機体の射撃が強くなる。
- 得点は撃墜した敵機と標的から数え、出撃の最後に経過時間とともに表示する。

## Acceptance Criteria

1. 操縦者は、敵機の編隊が飛来し、編隊を組んで飛ぶのをコックピットの映像で見る。操縦者が機体を旋回・上昇・下降させても、敵機は空中の同じ場所にとどまる。
2. 操縦者は、機体を飛ばして照準を敵機に合わせ、撃って撃墜できる。
3. 敵機は機体を撃ってくる。操縦者は弾が来るのが見え、機体を動かしてかわせる。当たったことと残りの装甲が分かる。
4. 操縦者はボタン 1 つで宙返り回避を出せる。機体は本物の宙返りをし、その間は敵の弾が当たらない。機体が安全に宙返りできない状況では、コックピットが受け付けない。
5. 編隊のあと、印刷した標的が最後の敵として現れる。撃墜すれば勝ち、装甲が尽きれば負け。どちらでも操縦者は結果と得点を見て、機体は操縦者が着陸させるまで飛び続ける。
6. 操縦者はコックピットで戦いの音（射撃、命中、撃墜、警告）を聞き、出撃の録画にもその音が入る。
7. 開発者は、Tello なしで、シミュレーターのドローンを使って PC で出撃を最後まで遊べる。

## Non-Functional Requirements

- 安全: [出撃 MVP](../sortie-mvp/prd.ja.md#non-functional-requirements) の要件はすべて引き続き守る。ゲームは、出撃に負けたときも含め、自分から機体を動かさない。ゲームが機体に送る動きは、操縦者が求めた宙返りだけ。
- MVP の標的だけの出撃は、これが実機で確かめられるまで残す。それを使って出撃映像を撮れるようにするため。

## Success Metrics

開発者が操縦者を兼ねて判断する。

- 戦いらしさ: 何回か出撃したあと、MVP と比べて戦いらしく感じたか、その理由を操縦者が書き残す。
- 飛ばすことの意味: 機体を飛ばして狙い、かわすことが楽しさの中心だったかを操縦者が書き残す。
- コンテンツ: 編隊の出てくる出撃映像を撮り、応募に使えるかを判断する。
