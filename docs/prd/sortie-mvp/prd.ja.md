# 出撃 MVP

[English](prd.md)

設計: [dd.md](dd.md) — 標的の大きさと検出できる距離、マーカーを見失ったときに操縦者に見えるもの。

## Problem

REAL FLIGHT は、実物の機体が現実の空で戦う IP として打ち出している。しかし、Quest 3 をかぶった操縦者が実機を狙えるのか、仮想のロックオンが戦いらしく感じられるのか、それが見る価値のある映像になるのかを示すものがまだない。TCIC IP INNOVATION AWARDS 2026 の応募（締切 10/29 17:00）には、その証拠となる出撃の映像が 10/26 までに必要になる。

## 導出

Story の2つのコアアクションを両方含む最小の切り出し。操縦者1人が1回出撃して標的を撃墜し、その出撃が他人の見られる映像になる。

## Overview

操縦者は Quest 3 をかぶり、そのブラウザでコックピットを開く。コックピットには Tello のカメラ映像がコックピットからの視界として映り、上に HUD が重なる。操縦者は Touch コントローラーで機体を飛ばし、ArUco マーカーを貼ったダンボールの標的を照準に収め続けて撃墜する。Quest はコックピットの映像を録画し、外からはスマホで機体を撮る。この2つを編集で合わせ、応募用の観戦映像にする。

### Goals

- 操縦者が Touch コントローラーで機体ごと向きを変え、標的を照準に収め続けられるか、操縦が楽しいかを確かめる。遅延の実測を先に行う。
- 標的を照準に収め続けて撃墜する操作が、戦っている手触りになるかを確かめる。
- 応募書に付ける観戦映像（コックピット + HUD、外からの視点付き）を作り、コンテンツとして成り立つかを判断する。

### Non-Goals

- 複数機・複数人、対戦
- Quest のネイティブアプリ
- 身体操作・ハンドトラッキングによる操縦
- 機体の外装・デザイン、アリーナ
- 配信、外カメラ映像のその場での合成（編集で合わせる）
- 応募前に、初めての操縦者や外部の観客で確かめること。今回は開発者1人で判断する
- Tello 以外のドローン。アダプタの境界は設けるが、2つ目のアダプタは作らない

## Domain Model

用語は [Glossary](../../../AGENTS.md#glossary) に従う（操縦者 = Pilot、機体 = Drone、出撃 = Sortie、標的 = Target、コックピット = Cockpit、観戦映像 = Sortie video）。

- 1回の出撃には、操縦者1人・機体1機と、部屋に置いた標的の組がある。標的をすべて撃墜するか、機体が着陸したら出撃が終わる。
- ロックオン: 標的がロックに必要な時間（最初は1秒、手触りで調整）続けて照準に入っていたら撃墜になる。照準から外れたらロックは解ける。ロックの後に発射ボタンも押させるかは、試遊して決める。

## Acceptance Criteria

1. 操縦やロックオンの作業を始める前に、開発者が、Quest のブラウザが WebCodecs で Tello の H.264 をデコードできるかを把握している。あわせて、ドローンのカメラからコックピットの表示までの遅延を実測して記録している。デコードできない場合は、[ADR 0001](../../adr/0001-typescript-only-thin-relay.md) の代替案に映像の経路を切り替え、その変更を ADR に残す。
2. 操縦者が Quest 3 のブラウザで USB 経由でコックピットを開くと、Tello のカメラ映像が WebXR 上に HUD 付きでライブで映る。
3. 操縦者が Touch コントローラーだけで、離陸、4軸の飛行、着陸、非常停止を行える。
4. 操縦者が標的を照準に収め続けて撃墜でき、HUD でロックオンの進み具合と残りの標的の数を確認できる。
5. 操縦者が、置いた標的をすべて撃墜する出撃を完了し、その経過時間を確認できる。
6. 開発者が、出撃のコックピット映像（HUD 付き）を Mac 上の動画ファイルとして受け取り、外カメラの映像と編集して応募書に添付できる観戦映像を作れる。

## Non-Functional Requirements

- 安全: 操縦者はいつでもコントローラーのボタン1つで機体を止められる。コックピットや中継との接続が切れた後も、機体が飛び続けない。
- 交換可能性: Tello 固有のコードは機体アダプタの内側に置く。
- プライバシー: repo は public なので、録画や生の映像は repo に入れない。

## Success Metrics

操縦者でもある開発者が自分で判断するため、結果は楽観に寄る。外部の反応は応募の後に確かめる。

- 照準: 実測した遅延を記録し、操縦者が置いたままの標的を照準に収め続けられる。操縦が楽しかったかどうかとその理由を、操縦者が書き残す。
- 戦いの手触り: 操縦者が出撃を完了し、ロックオンが戦いに感じられたか、ただ待っているだけに感じたかを書き残す。
- コンテンツ: 出撃1回分の観戦映像を、10/29 までに応募書に添付する。
